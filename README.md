# Zygos - Gestión Inteligente de Deudas

Esta es una aplicación Next.js diseñada para la gestión de deudas grupales, cobros fijos, arriendos deportivos y división colaborativa de cuentas.

## 🚀 Características
- **División inteligente**: Cuentas claras por ítem y por cabezas.
- **Invitados fluidos**: Asigna consumos a acompañantes sin cuenta vinculándolos a un responsable.
- **Seguridad primero**: Doble flujo de confirmación y estado de revisión para reportar pagos sin errores.
- **PWA lista**: Instala Zygos en tu dispositivo directamente desde el navegador.
